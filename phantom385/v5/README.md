# Phantom 3.5.85 — исправление лицензии v5

Исправлена потеря лицензии после появления меню: в подтверждение добавлен SHA-512 неизменяемых сегментов загруженного игрового модуля. В v4 это поле оставалось нулевым, и штатная проверка модуля отклоняла лицензию после запуска.

Ключ: **`@Icon_Crack`**. Android-версия **107 / 3.5.85-icon5**. Нативные библиотеки и обработчики игровых функций совпадают с v4.

Обновить Phantom **внутри LuluBox** → полностью закрыть LuluBox и игру → открыть Phantom, дождаться подготовки обновлённого модуля → запустить игру и ввести ключ.

В изолированной проверке выполнены фактический DEX, нативная активация после запуска игрового модуля, истечение и обновление сессии, отклонение повреждённой подписи и изменённого образа. Проверены CRC, подписи APK v2/v3 и выравнивание 16 КБ. Android API и окружение игры в этих проверках заменены тестовыми адаптерами; на телефоне сборка не запускалась.

Размер: 4604918 байт. SHA-256: `fcfdc8d21dc4f1c802099358df8dfc38fc49a3d43f4f81b951b54d0ca893d794`.

В протоколе OXL7 используются два разных SHA-512: смещение 120 — неизменяемые PT_LOAD-сегменты ELF, смещение 232 — полный файл. Оба значения подписаны. Проверки целостности сохранены.

`probe_live_image.py` исполняет нативный код с ненулевой базой загрузки, правами сегментов памяти и включённой проверкой после запуска; v4 отклоняется, v5 принимается. Тест не выполняет игровой поток и не заменяет проверку в LuluBox на устройстве.
