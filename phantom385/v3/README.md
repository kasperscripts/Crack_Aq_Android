Ключ — **`@Icon_Crack`**. Подпись, Telegram и изменения открытия панели из v2 сохранены.

В v2 ключ подтверждался, но нативная загрузка останавливалась с `payload_native_digest_mismatch`; экран показывал общий `INIT_NATIVE`. В локальном подписанном доказательстве передавался SHA-256, но отсутствовал отдельный SHA-512 игрового ELF. Штатный загрузчик сравнивает SHA-512 запечатанного memfd с 64 байтами доказательства по смещению 232 и отклоняет несовпадение.

В v3 передаётся SHA-512 фактического встроенного модуля. Нативные проверки остаются включёнными. Все ELF, включая игровые обработчики и загрузчики, побайтно совпадают с v2; исправлены данные подписанного ответа в Java. При другой ошибке экран теперь показывает ограниченный по длине исходный текст `ERROR:`, чтобы причина была доступна без root и компьютера.
