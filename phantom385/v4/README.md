1. Обновить Phantom **внутри LuluBox** этим APK, сохранив прежнюю запись приложения.
2. Полностью остановить LuluBox через настройки приложений Android и открыть заново.
3. Открыть Phantom, дождаться завершения подготовки модуля, затем запустить Oxide.
