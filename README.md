# AQ Android v4 — запуск меню и сохранение исходного APK

[Скачать APK v4 в одном ZIP](https://github.com/kasperscripts/Crack_Aq_Android/releases/download/aq-icon-crack-v4/AQ_Icon_Crack_v4.zip)

Распакуйте `AQ_Icon_Crack.apk` и установите поверх v3. Сертификат прежний. Ключ: **`@Icon_Crack`**. Канал: https://t.me/Icon_Crack.

В отрисовке воспроизведено чтение через нулевую таблицу игровых функций. Добавлена проверка: пока таблицы нет, используется существующая ветка отсутствующей камеры; после создания таблицы выполняется прежний код. В строке состояния меню виден этап запуска: `Game module loading`, `Waiting for game world` или `Game world ready`.

Изменён способ сборки. В v2/v3 сохранённые игровые данные переупаковывались с другими заголовками и расположением ZIP-записей. v4 сохраняет исходные локальные заголовки и физические позиции всех 1750 остальных записей APK, включая DEX, загрузчик, игровые библиотеки и ресурсы. `libAQR.so` остаётся первой записью; его сжатый размер сохранён посредством допустимых пустых блоков DEFLATE. Для подписи v2/v3 используется Android apksig без пересоздания локальных ZIP-записей.

Проверены 12 сценариев авторизации и 9 сценариев запуска, включая воспроизведение ошибки в v3, отсутствие таблицы, пустую и заполненную таблицу, а также состояния загрузки. Проверены сохранённые сжатые данные, расположение записей, подпись и выравнивание. GitHub Actions дополнительно проверяет полную распаковку готового ZIP64 через Python, Java и Info-ZIP.

Выпуск предназначен для проверки на устройстве. Вылет на конкретном телефоне и фактическая работа ESP руд пока не воспроизведены. Сохранение структуры APK устраняет отличие от оригинала; связь этого отличия с неработающим ESP ещё не подтверждена. Игровые обработчики функций сохранены.

Вход остаётся локальным по `@Icon_Crack` с конфигурацией v3, полученной ранее из проверенного подписанного ответа. Полный исходный обработчик ответа в ARM64-проверке даёт те же четыре игровых адреса. Исходный лицензионный ключ и закрытый ключ подписи в APK и репозиторий не включены.
