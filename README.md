# AQ Android v2 — исправление исчезающего меню

[Скачать исправленный APK в ZIP](https://github.com/kasperscripts/Crack_Aq_Android/releases/download/aq-icon-crack-v2/AQ_Icon_Crack_v2.zip)

Распакуйте единственный `AQ_Icon_Crack.apk` и установите обновление. Ключ: **`@Icon_Crack`**. Используется тот же сертификат, что в v1. Адрес канала в окне входа: https://t.me/Icon_Crack.

В v1 после сообщения «Key verified» скрывалось окно входа, но состояние сессии оставалось неавторизованным: обе проверки основного меню отклоняли его. В v2 исправлены состояние сессии, его контрольное значение и локальный билет отображения. Проверки меню используют исходный код приложения; функции отрисовки не изменены.

Ошибка v1 воспроизведена в ARM64: окно входа скрыто, обе проверки меню возвращают отказ. В v2 12 сценариев проверки проходят, включая настоящий код проверки допуска в основном рендерере и теле меню, неверные ключи, сохранение ключа и повторный вход. Физический телефон и графика игры не тестировались.

Манифест, DEX, загрузчик игры, остальные библиотеки и игровые ресурсы сохранены. SHA-256 всех 1750 сохранённых сжатых записей APK совпадает с исходником. Новый APK подписан по схемам v2/v3 и проверен на выравнивание.

Для ускорения публикации GitHub Actions получает небольшой `aq-v2.patch`, восстанавливает **точные байты уже подписанного APK** из опубликованной v1 и проверяет полный SHA-256. Затем создаёт один ZIP64, проверяет распаковку через Python/Java/Info-ZIP и публикует готовый архив. Пользователю патч отдельно не нужен; ключи подписи в GitHub не передаются.

Серверный ключ, предоставленный для исходного приложения, не включён в APK или репозиторий. Исходный релиз: [`q`](https://github.com/kasperscripts/Crack_Aq_Android/releases/tag/q). Предыдущая сборка v1 остаётся в истории релизов.
